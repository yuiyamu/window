# Windows Classic Window Generator

A utility to generate images of simple Windows Classic-style windows. A hosted version is available at <https://tpenguinltg.github.io/winclassic-window/> .

This tool was originally made for [PenbuVT](https://www.penbuvt.ca/) for his overlays.
